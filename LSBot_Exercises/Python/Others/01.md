# PY120
## Problem 1: LRU Cache

Design and implement a Least Recently Used (LRU) cache. An LRU cache has a fixed `capacity`. When it is full and a new key is added, it evicts the least recently used key to make room.

Implement the `LRUCache` class:

- `LRUCache(capacity)` — Initialize the cache with a positive `capacity`.
- `get(key)` — Return the value for `key` if it exists, otherwise return `-1`.
- `put(key, value)` — Update the value for `key` if it already exists. Otherwise add the key-value pair. If adding it would exceed `capacity`, evict the least recently used key.

A key counts as "recently used" when it is either read via `get` or written via `put`. Both `get` and `put` must run in **O(1)** average time.

## Examples:

```python
cache = LRUCache(2)

cache.put(1, 1)   # cache is {1=1}
cache.put(2, 2)   # cache is {1=1, 2=2}
print(cache.get(1))  # => 1   (key 1 is now most recently used)
cache.put(3, 3)   # evicts the least recently used key (2); cache is {1=1, 3=3}
print(cache.get(2))  # => -1  (not found)
cache.put(4, 4)   # evicts key 1; cache is {4=4, 3=3}
print(cache.get(1))  # => -1  (not found)
print(cache.get(3))  # => 3
print(cache.get(4))  # => 4
```

<details>
<summary>Solution:</summary>

Python's `dict` preserves insertion order (Python 3.7+) and offers O(1) `pop` and re-insert. Use it to track recency: whenever a key is accessed, pop and re-insert it so it lands at the "most recently used" end, and when over capacity, evict the first key.

```python
class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.store = {}

    def get(self, key):
        if key not in self.store:
            return -1

        value = self.store.pop(key)
        self.store[key] = value  # re-insert moves key to the "most recently used" end
        return value

    def put(self, key, value):
        self.store.pop(key, None)
        self.store[key] = value

        if len(self.store) > self.capacity:
            oldest_key = next(iter(self.store))
            del self.store[oldest_key]
```
