# JS120
## Problem 1: LRU Cache

Design and implement a Least Recently Used (LRU) cache. An LRU cache has a fixed `capacity`. When it is full and a new key is added, it evicts the least recently used key to make room.

Implement the `LRUCache` class:

- `new LRUCache(capacity)` — Initialize the cache with a positive `capacity`.
- `get(key)` — Return the value for `key` if it exists, otherwise return `-1`.
- `put(key, value)` — Update the value for `key` if it already exists. Otherwise add the key-value pair. If adding it would exceed `capacity`, evict the least recently used key.

A key counts as "recently used" when it is either read via `get` or written via `put`. Both `get` and `put` must run in **O(1)** average time.

## Examples:

```js
const cache = new LRUCache(2);

cache.put(1, 1);   // cache is {1=1}
cache.put(2, 2);   // cache is {1=1, 2=2}
console.log(cache.get(1));  // => 1   (key 1 is now most recently used)
cache.put(3, 3);   // evicts the least recently used key (2); cache is {1=1, 3=3}
console.log(cache.get(2));  // => -1  (not found)
cache.put(4, 4);   // evicts key 1; cache is {4=4, 3=3}
console.log(cache.get(1));  // => -1  (not found)
console.log(cache.get(3));  // => 3
console.log(cache.get(4));  // => 4
```

<details>
<summary>Solution:</summary>

JavaScript's `Map` preserves insertion order for all key types and offers O(1) `delete` and re-`set`. (A plain object would not work here — integer-like keys are iterated in ascending numeric order regardless of insertion.) Use a `Map` to track recency: whenever a key is accessed, delete and re-set it so it lands at the "most recently used" end, and when over capacity, evict the first key.

```js
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity;
    this.store = new Map();
  }

  get(key) {
    if (!this.store.has(key)) return -1;

    const value = this.store.get(key);
    this.store.delete(key);
    this.store.set(key, value); // re-set moves key to the "most recently used" end
    return value;
  }

  put(key, value) {
    this.store.delete(key);
    this.store.set(key, value);

    if (this.store.size > this.capacity) {
      const oldestKey = this.store.keys().next().value;
      this.store.delete(oldestKey);
    }
  }
}
```
